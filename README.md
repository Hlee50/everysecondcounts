# Every Second Counts
This is a shareable countdown timer built with React and TypeScript that lets you count down to any future date, up to 10 years from now, displaying the remaining time in `HH:MM:SS` format.


## Accessing and using the timer
- https://everysecondcountstimer.vercel.app

There are two ways to set a countdown:

### Date Picker
Select a date from the calendar.

### URL Date Parameter
Add a `date` parameter to the URL to set the date directly in `YYYY-MM-DD` format.
```
https://everysecondcountstimer.vercel.app/?date=2027-06-25
```


The timer's link can be copied and shared.
